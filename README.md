# 🚑 Cloud-Based Ambulance Dispatch Coordination Platform

A web-based ambulance dispatch coordination system designed to connect patients, dispatchers, and ambulance drivers through a centralized platform.

## 📌 Project Overview

The Cloud-Based Ambulance Dispatch Coordination Platform helps manage emergency ambulance requests efficiently.

The system allows:

- Patients to request an ambulance.
- Dispatchers to view emergency requests.
- Dispatchers to assign available ambulances.
- Drivers to view assigned emergency requests.
- Drivers to update the emergency status.
- The system to automatically update ambulance availability after completing a request.

## 🎯 Objectives

- Reduce the time required to coordinate ambulance services.
- Provide centralized emergency request management.
- Improve communication between dispatchers and ambulance drivers.
- Track ambulance request status.
- Maintain emergency request information in a database.
